## 📁 Repository Structure

* **`final_paper_GML.pdf`**: The comprehensive project report. It builds upon the original paper *"Local Risk Bounds for Statistical Aggregation"* by Mourtada et al., exploring alternative theoretical settings and practical implementations of the proposed methods.
* **`experiments_ULA.ipynb`**: A Jupyter Notebook containing the Unadjusted Langevin Algorithm (ULA) implementations and the empirical MCMC simulations discussed in the report.
